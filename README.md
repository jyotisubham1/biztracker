# Business International Money Tracker

🎲 Real-time money tracker for the Business International board game.

## Features
- ✅ Record payments instantly
- ✅ Real-time balance calculations
- ✅ Transaction history
- ✅ Undo functionality
- ✅ Auto-save games locally
- ✅ No backend needed!

## How to Use
1. Open the app in your browser
2. Add players and starting balances
3. Click "Record Payment" to track transactions
4. Balances update automatically
5. Games save automatically on your device

## Getting Started
See `docs/QUICK_START.md` for deployment instructions.

## Tech Stack
- Pure HTML/CSS/JavaScript
- Browser LocalStorage (no backend)
- GitHub Pages hosting (free!)
